# 🍲 Recipe Explorer (Frontend)

A stylish and animated React + Material UI application to search, filter, and explore recipes.  
Built with **React**, **Axios**, **Material UI**, and custom animations.

---

## ✨ Features
- 🔎 **Search & Filters**: Filter recipes by title, cuisine, rating, calories, and total time.
- 📄 **Pagination**: Browse recipes with previous/next controls.
- ⭐ **Ratings**: View recipe ratings with star display.
- 🎨 **Advanced Styling**: Gradient background, glassmorphism cards, neon buttons, animations.
- 📖 **Drawer View**: Detailed view with description and nutrients.
